Work 08

Each entry says what I measured, and where my own idea fell short.

  1. 01 Does Supabase Storage keep S3's conditional-write promises? 32 of 32 clients won a create-once race on master; exactly 1 with the community fix. Study / Python / TypeScript / S3

    Supabase's S3 endpoint ignored If-None-Match, so concurrent "create-once" calls all succeeded. I built master and a community fix from source, ran a 53-case conformance matrix on two storage backends, and checked create-once under container, Postgres and network faults. The fix still leaves If-Match (compare-and-swap) ignored, and my write-up says so.

    Code and results Issue #1635 Review of the fix, #1636 Draft PR #1712: 8 regression tests

  2. 02 SigNoz MCP server: a tool answer too big for AI clients A tool returned 115,526 characters; with my change, 5,882. Pull request open. Open source / Go / MCP

    A tool that lists a service's slowest operations returned more than Claude Code accepts in one tool result. My pull request adds an optional limit (default 50) and a note saying how many rows were omitted, so the full table is one parameter away. Another contributor built it independently and confirmed it. It is waiting for a maintainer (open as of 19 November 2026).

    Pull request #455 Issue #452

  3. 03 s3lin A typed Python library that finds where concurrent S3 histories break. Library / Python / PyPI

    A linearizability checker for S3 conditional-write histories, packaged with no runtime dependencies. It names the key and the operation where a history stops making sense. On 54 recorded histories (288,820 operations) it agrees with my original checker on all 1,245 keys. Version 0.1.0, so brand new.

    PyPI GitHub

  4. 04 LLM router recovery simulator Routers modelled on SGLang, llm-d and Dynamo, tested after a replica failure. Study / Python / Simulation

    A trace-driven simulator of LLM request routing: 8 vLLM-like replicas, public Mooncake traces, 10 policies modelled on SGLang, llm-d, Dynamo and LMetric, 10 seeds. My recovery-aware router recovered from a 30-second replica failure in 9 of 9 held-out seeds on both traces; variants without its recompute budget drifted into a 13 to 19 s p99 state at 95% load, against 3.8 to 5.5 s with it. It is not faster than SGLang's policy at recovery (165 s vs 125 s median on one trace).

    Write-up on request. A simulation, not production.

  5. 05 NineLives An on-call agent whose memory survives node failures. Agents / Python / FastAPI / CockroachDB

    Recalls similar past incidents by vector search (12 of 12 correct on benchmark cases) and runs only allowlisted fixes. Memory lives on a 3-node CockroachDB cluster, written in the same transaction as each fix, and it kept serving through live node kills (0.11 s and 6.85 s pauses). An ablation showed the memory is load-bearing.

    GitHub

  6. 06 Friday A voice assistant that hands work to parallel agents, with human approval. Agents / Python / Claude Agent SDK / MCP

    A macOS assistant where a conversation agent hands work to parallel task and research agents, with human approval before risky actions and cost tracked per agent. I traced 7 of 18 failed runs to two root causes, including runaway fan-out (293 subagents in one run), and capped it at 10 per request.

    GitHub

  7. 07 HypeCart A spoken pitch becomes five ad assets in four languages. Voice / React / FastAPI / asyncio

    Turns a short spoken pitch into 5 ad assets in English, Malayalam, Hindi and Telugu. Four models run concurrently with fault isolation, and a fast path returns the first assets in under 3 seconds.

    GitHub

  8. 08 Robots and embedded systems A RoboCup rescue robot, a farm intrusion mesh, and a 95 KB model on a Raspberry Pi. Robotics / ROS 2 / Gazebo / Edge AI

    RoboCup German Open 2026 rescue robot: ROS 2 and Gazebo modules and control interfaces for two robotic arms. Earlier: AgriShield, a solar-powered Zigbee-mesh farmland intrusion system (Bronze Medal, AgriXcelerate 2026), and a 95 KB TensorFlow Lite fault-detection model that runs in 3.75 ms on a Raspberry Pi 4.
